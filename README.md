# NEX Installer

Portable, offline Windows software and font installation workspace.

Development starts with Phase 1: .NET 10 WPF application foundation.
All source control is local. `main` is reserved for explicitly approved stable
milestones; verified feature branches merge into `dev` with merge commits.
Installer binaries, font files, logs, local configuration, and customer data
must not be committed. See the development documentation as implementation grows.
